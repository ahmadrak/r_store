# 🛒 E-Commerce Web Application

A full-stack e-commerce web application that allows users to browse and purchase products, while admins can manage the store through a secure dashboard.

---

## 🚀 Features

### 👤 User
- Browse available products
- View product details
- Add items to cart
- Purchase products

### 🛠️ Admin
- Add new products
- Edit existing products
- Delete products
- Role-based access control

### 🔐 Authentication
- Session-based authentication
- Protected routes for admin access

### ⚙️ General
- RESTful API
- Secure backend structure
- PostgreSQL database integration

---

## 🧰 Tech Stack

### Backend
- Node.js
- Express.js
- PostgreSQL
- Express Session

### Frontend
- React (Vite)
- Redux

### Other Tools
- REST API architecture
